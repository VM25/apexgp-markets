# Overview

ApexGP Markets transforms historical Formula One races into replayable event markets.

Users receive a fixed portfolio and participate in dynamic probability markets while historical races unfold.

As information enters the system, prices move.

As prices move, positions change.

As positions change, portfolio outcomes emerge.

The platform studies how markets react to uncertainty.

This project is not designed to predict races.

This project is designed to study how information becomes price and how price becomes portfolio behavior.

No real money.

No accounts.

No persistence.

Every session begins with a fresh portfolio.

---

# Core Thesis

Markets evolve through information.

Formula One races evolve similarly.

Each race generates sequential updates:

* Lap progression
* Pit stops
* Tire changes
* Safety cars
* Penalties
* Retirements
* Weather changes
* Position shifts

These become market events.

| Formula One       | Market Analog           |
| ----------------- | ----------------------- |
| Pit Stop          | Earnings Surprise       |
| Safety Car        | Macro Shock             |
| Weather Change    | Volatility Regime Shift |
| Lap Update        | Tick Update             |
| Championship      | Futures Market          |
| Portfolio         | Trading Book            |
| DNF               | Credit Event            |
| Event Probability | Market Price            |
